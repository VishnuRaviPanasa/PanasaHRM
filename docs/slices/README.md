# docs/slices/

Archived slice cards (`SL-NNN.md`), written at slice close. Together they are the real project
history - more useful than the commit log, because each records the goal, the acceptance criteria
**as test names**, the change class, and what actually happened.

A slice may only be closed when **every acceptance criterion names a test that exists and passes**.
That is what stops prose state drifting from reality.
